# Simple image viewer:
A simple image viewer that only supports `.ppm` files for now.

## Repo structure:
```sh
imageview/
├── assets/
│   ├── abstarct.ppm
│   ├── android.ppm
│   └── Clang.ppm
├── bin/
│   └── main
├── README.md
├── Makefile
└── src/
    └── main.c
```

## Building/Running:
- `make`        compile the program
- `make run`    run the example
- `make clean`  delete the program
